# 定點近戰敵人

選取場景中的實體平台，使用 GameObject > Morld > Enemy Spawn Point。
首次使用會建立 `Assets/_Project/Prefabs/Enemies` 中的敵人與生成點 Prefab；之後可直接拖生成點到場景。
生成點的位置是敵人的腳底。請確認上方至少有 1 單位淨空，出生位置不要放入牆內。
每個生成點只生成一隻，預設不重生；可開啟 respawn 並設定延遲。

敵人 Prefab 可調 reach、verticalReach、windup（預設 0.65 秒）、recovery（1 秒）。攻擊固定扣 1 血。
攻擊距離依目前視角的水平與垂直距離判定；敵人到玩家的實體連線有牆便不能命中，忽略投影代理碰撞體。
前搖開始鎖定左右方向；離開範圍、跳開或繞到另一側可閃避。轉視角會取消尚未出手的攻擊。
玩家左下顯示測試血量，F9 補滿；死亡目前只停止敵人攻擊，未接正式死亡／重生流程。
主玩家預設 5 血，Health.oneDamagePerHit 保證每次有效受擊固定扣 1，包含沿用舊攻擊設定的傷害來源。
F10 或左下 HP tools 開啟測試面板：扣 1（含完整受擊反應）、補 1、補滿、調整最大血量 1–9、切換無敵、選擇測試攻擊來自左或右。
測試扣血會忽略無敵，方便反覆測擊退。面板調整僅在執行期間有效，不會覆寫 Prefab。

## 美術接入

- Gameplay 根物件：保留 Health、CharacterController、StationaryMeleeEnemy，根座標是腳底。
- VisualRoot：刪除 Placeholder 子物件後放入模型或 Spine 美術。動畫不要移動 Gameplay 根物件。
- WarningAnchor：調整頭頂預警位置。warningIcon 可指定任意美術子物件，僅前搖期間啟用。
- EnemyWarningBillboard：預警圖示朝鏡頭；若美術自行處理朝向可移除。
- Animator 欄位選填：CombatState(int) = Idle 0 / Windup 1 / Attack 2 / Recovery 3 / Dead 4；Facing(float) = -1 或 1。
- onWindup / onAttack / onRecovery / onDeath 可接特效、動畫或音效。真正扣血只在前搖結束時執行一次，不依賴動畫事件。

現有 Monster 是舊格子測試使用的物件，與這個新敵人分開保留。

## 敵人種類與關卡配置

`Prefabs/Enemies/QuickGuard.asset`、`HeavyGuard.asset`、`PatrolGuard.asset` 可直接拖到生成點的「敵人種類」。三者共用暫用外觀，可各自指定不同美術 Prefab。
快攻前搖 0.35 秒、最短間隔 1.2 秒；慢攻前搖 1.1 秒、最短間隔 3 秒；巡邏沿生成點本地 X 軸各走 2 單位，速度 1。
新增種類可用 Project 視窗右鍵 Create > Morld > Enemy Type，或複製既有種類資產。

種類包含：血量、定點／巡邏、巡邏速度與距離、水平／垂直攻擊距離、前搖、出手展示時間、收招、最短攻擊間隔。所有攻擊維持 1 傷害。
最短攻擊間隔從開始前搖起算；出手與收招尚未結束時不能進入下一次前搖。出手展示期間不會重複扣血。
若只想調整一個遭遇，點「複製種類參數到本地覆寫」，再調這個生成點的數值；不會修改共用種類資產。
關閉本地覆寫即可重新使用共用設定。參數在生成時載入，Play 中改設定後需清除、重新生成才會套用。

黃色框是目前視角攻擊範圍，青色線是巡邏範圍。旋轉生成點可改變實體巡邏方向，視角旋轉不會改寫巡邏路線。
巡邏採實體地板／牆壁判定，遇到牆或邊緣折返，不具備玩家的投影跨平台或自動深度繞行能力。
生成點可關閉「進場生成」，由之後的房間觸發器呼叫 Spawn()；Despawn() 可清除當前敵人；重生重新套用同一份設定。

### 擴充不同 AI 與攻擊

Prefab 可掛繼承 `EnemyBehaviour` 的元件，指定給 customBehaviour：Initialize 接收生成時初始化；Tick 處理追蹤／巡邏等決策；PerformAttack 可接管出手（回傳 true），回傳 false 則使用現有近戰。
Tick 需處理 Target 尚不存在的情況，並依 State 決定何時能移動。地面位移用 TryMoveOnGround，保持 CharacterController 碰撞與邊緣檢查。
目前已完成定點、巡邏近戰及 3D A* 地面追擊；遠攻、衝刺等仍需各自實作策略，不會只因新增設定資產便自動具備這些能力。
現有 VisualRoot、WarningAnchor、動畫事件維持使用；擴充種類不必更換生成點系統。

## 3D A* 試作

最快試用：選一塊寬地板，GameObject > Morld > 3D A Star Chase Test。
工具會放置套用 ChaseGuard 的生成點，建立並連接預設 12×6×12 尋路區域，選中區域供調整。這個操作可 Undo。
調整區域使它覆蓋玩家與敵人會走到的實體地板及頭頂空間，再按「重建 3D 地板路網」，存場景後 Play。
也可獨立用 GameObject > Morld > 3D Enemy Navigation Area 建立區域，再指定給生成點。

- 區域以世界 XZ 格子掃描所有地板層，不把上下層投影成同一個平面。最多 4096 個 XZ 格、8192 個樓層節點。
- 區域半徑／高度至少覆蓋敵人實際碰撞箱；地形圖層需包含牆與地板。系統排除玩家、敵人及深度代理碰撞體。
- 綠色是烘焙路網；Play 選中生成後敵人物件可看紫色追擊路線；紅色表示區域設定已變更，需重建。
- 追擊距離按實體 3D 距離計算；不能走過缺口、穿牆、跳躍、爬階或使用玩家的深度繞行。不通時停止，不會傳送。先在平地與寬通道測試。
- 視角旋轉不改路網；旋轉期間暫停追擊，前搖與收招也暫停追擊。攻擊仍沿用先前決定的畫面 2D 距離＋實體牆阻擋。
- 修改地形需重建；運行時只檢查下一段是否仍可走，不會自動重建所有節點。此版以靜態關卡為主。
- 種類／本地覆寫可設追擊速度、3D 偵測距離、停靠距離與重新規劃間隔（預設 0.5 秒）。多區域需各自指定；此版沒有跨區域路徑連接。
- 追擊敵人頭上與 Inspector 會顯示當前狀態；Console 的 `[Morld A*]` 記錄狀態變更。EnemyChaseBehaviour.showStatus 可關閉頭頂顯示與紀錄。
- 尺寸檢查使用 CharacterController 的實際膠囊尺寸，不包含接觸外框；尋路前會在有限距離內對準腳下真實地板，避免 skinWidth 的接觸偏差被當作斷路。敵人忽略已存在的玩家深度代理碰撞體。

搜尋回歸：Morld > Tests > Run A Star Search Regression。涵蓋加權最短路徑、起終點相同、不通圖、空圖，及 100 組固定種子障礙網格與 BFS 對照。

## 敵人視野

所有敵人的首次發現與開始攻擊均需實際看見玩家，不再使用方圓距離直接發現。
預設水平視角 110 度、垂直視角 100 度、最遠距離 8，沿生成點藍色 Z 軸作為初始正面；可旋轉生成點調整。
選中生成點或敵人可看到橘色水平視野扇形。視野使用世界 3D 朝向，與鏡頭旋轉無關；玩家在背後不會觸發首次發現。
視線會被實體牆擋住，忽略投影代理；中心與上半身任一射線可見即可發現。eyeAnchor 可替換成美術的眼睛／頭部位置。
巡邏及追擊成功移動時根物件轉向移動方向；待機時不會憑空轉向尚未發現的玩家。
追擊失去視野後只前往最後看見的位置，預設短暫記憶 1.5 秒；之後進入調查階段繼續走向該位置，不讀取隱藏玩家的新位置。完整流程見下方行為樹。
已經開始的前搖維持原攻擊方向與命中規則，轉到背後的閃避仍由既有攻擊判定處理。
視野掃描與角色轉向採平滑銜接：掃視轉為注意玩家時慢慢回正，追擊拐角與返回巡邏朝向不會瞬間旋轉。種類可調 turnSmoothTime（0.2 秒）、maxTurnSpeed（180 度／秒）、scanSmoothTime（0.25 秒）；不改變 110 度視角、單側 50 度掃描或遮擋規則。

## 巡邏、追擊、觀察與返回行為樹

使用 `ChaseGuard` 或移動方式為「3D A* 追擊」的種類。其反應式行為樹優先序為：強制返回 > 目視追擊 > 最後位置調查／觀察 > 巡邏。每次更新重新評估，因此觀察中發現玩家可立即切回追擊。

在生成點按「新增巡邏點」，依序加入場景位置；也可拖入既有 Transform。點座標代表腳底，點的藍色 Z 軸代表抵達後的警戒朝向。選中生成點即可拖曳各點的手把，青色線與編號顯示順序。
沒有巡邏點時留守出生點；單一點作為哨位；多點可設往返或循環，抵達後停留 `patrolWait` 秒（預設 1.5）。

- 看見玩家：以 A* 追擊並沿用原前搖／攻擊。
- 失去視野：只前往已保存的最後目擊位置。
- 到達最後位置：完全停止移動，左右各 50 度觀察，**抵達後才開始計時**，預設 3 秒；可調 `searchDuration`。
- 追擊切到最後位置調查時沿用既有路線，不清空路徑或等待記憶倒數；重新規劃完成才換路，並略過可直達的起點接入節點，避免折返。失去視野後取消尚未完成的出手，收招計時可與前往最後位置的移動並行。
- 觀察時再次發現玩家：立即追擊；觀察結束仍未發現：返回距離最近的巡邏點，無點則回出生點。
- 敵人或可見玩家超出出生點半徑 `leashRadius`（預設 12），或追擊／調查超過 `maxChaseTime`（15 秒）：放棄追擊並返回；原地觀察不會被追擊計時提前截斷。
- 路徑連續失敗超過 `unreachableTimeout`（3 秒）：放棄調查／追擊並返回。返回路線不通時停住、定期重試，絕不傳送穿牆。
- 玩家所在位置不可達或不在實體地板上時，追擊／調查改為走到「敵人目前連通路網內，3D 距離最接近目標」的節點；不會直接選取隔著缺口的另一個平台。仍按最短路徑走到該節點，最後一段不會強行延伸到玩家腳下。
- 看得見玩家時，在最近可達位置等待並定期重新規劃；玩家回到可達位置便恢復完整追擊。失去視野時只用最後目擊座標挑選最近可達地板，到達後原地觀察再返回。追擊半徑與最長時間仍有效；巡邏／返回需完整路徑，不把近似抵達當作回到巡邏點。
- 返回期間忽略玩家並取消未完成的攻擊；抵達後保留 1 秒緩衝，再恢復偵測與巡邏，避免邊界反覆折返。

本版是程式化可擴充行為樹，尚無節點拖拉圖形編輯器。種類／本地覆寫可調上述數值，場景巡邏點只保存在生成點上，不寫入共用種類資產。
回歸檢查：Morld > Tests > Run Enemy Decision Tree Regression，確認巡邏回退、目標重新發現與強制返回優先序。

## 玩家接觸與閃避

新敵人自動附加 EnemyPlayerContact，與玩家碰撞體採 IgnoreCollision 配對；玩家路徑及平台投影查詢也排除敵人。
每幀只對敵人做膠囊重疊分離，敵人使用 CharacterController.Move，仍受實體牆限制；不修改玩家座標、速度、重力或支撐狀態。敵人無處可退時玩家仍可通過。新增玩家與 F8 返回後會恢復忽略配對。
受擊硬直期間，EnemyPlayerContact.ignoreDepthWhileHit 預設啟用：接觸依當前畫面左右及垂直的投影膠囊判斷，忽略雙方深度差；玩家可以沿畫面左右把敵人推開。只移動敵人，敵人實際深度不變、牆仍阻擋，受擊結束後恢復實體 3D 接觸規則。

左 Shift 閃避；手把依偵測配置使用下方按鍵跳躍、右方按鍵閃避：原生 PS5 為 ×／○，Xbox 為 A／B。上方按鍵暫不配置遊戲操作。
GamepadMapping 每 0.5 秒檢查裝置並支援重新連接，按下正面按鈕的裝置會成為目前配置來源；左上角顯示配置及原始按鈕編號。PlayerController.gamepadLayout 可手動指定 Auto／PlayStation／Xbox。
Windows 原生 PS HID 採 □0／×1／○2／△3；若 Steam Input 或轉接器呈現為 Xbox，則使用其 Xbox 輸出映射。此為舊 Input Manager 的裝置名稱辨識，未知裝置以 Xbox 配置為預設，並非所有品牌的通用校準。
預設衝刺 0.18 秒，速度 14，冷卻 0.65 秒，前 0.12 秒無敵。保持原垂直速度與重力，沿當前畫面左右移動，不改深度規則；方向鍵決定方向，無輸入沿最後移動方向。
閃避走既有固定小步長的移動／繞牆／落地流程，不穿牆；切換視角、被強制傷害、禁用玩家或 F8 返回會取消閃避並清除閃避無敵。
地面可按冷卻重複使用，空中每次落地前最多一次；受擊硬直、死亡或旋轉期間不能發動。衝刺期間不跳躍／下落／使用技能／互動。
PlayerController 可調閃避參數，onDodgeStarted / onDodgeEnded 預留動畫、音效及特效；輸入測試紀錄會記下成功發動。測試面板強制扣血仍可忽略閃避無敵。

## 玩家近戰與敵人受擊

滑鼠左鍵／PS5 □ 攻擊（Xbox 對應 X）；× 跳、○ 閃避、△ 仍留空。
MorldPlayer Prefab 的 PlayerMeleeAttack 可調攻擊鍵、距離規則、水平距離（0.9）、垂直距離（0.6）、最大深度差（3）、前搖（0.1 秒）、收招（0.25 秒）。
出手方向於按下時鎖定，整段動作不連發；每次出手對各敵人最多造成 1 傷害。預設可同時擊中範圍內多隻敵人。
出手時先檢查前方水平／垂直近戰範圍及視角深度差 3 格上限；敵人若在主遊戲鏡頭內可見，就忽略玩家到敵人的遮擋。不可見時仍採原本實體連線無阻擋的命中規則。
鏡頭可見性以美術 Renderer 範圍多點採樣、鏡頭裁切範圍及可見實體遮擋判斷，忽略 Scene 視窗、玩家與深度代理；屬幾何近似，並非逐像素透明度／Shader 可見性測試。
空中也可攻擊；閃避、受擊、死亡、旋轉或切換視角會取消尚未完成的攻擊。onWindup / onStrike / onHit / onFinished 可接動畫、斬擊特效、命中音效。
暫用攻擊提示已改為前方明顯弧形揮擊：黃色前搖、綠色命中、橘色揮空，附準備／命中／揮空文字。showAttackHint 可關閉以替換正式動畫；strikeVisualDuration 預設 0.24 秒。
揮空時觸發 onMiss，額外收招 missPenalty 預設 0.2 秒，同時間鎖住移動、跳躍、閃避、技能與互動；仍保留重力、既有垂直速度與平台承載。命中任一敵人則不觸發懲罰，敵人在無敵期但已接觸攻擊範圍也不算揮空。missPenalty 設 0 可關閉。

主敵人與各種類預設 5 血，頭頂有血量條及數字。血量仍由種類／生成點覆寫控制，0 血停止 AI 和攻擊，是否重生由生成點決定。
EnemyHitResponse 掛在敵人 Gameplay 根物件：0.045 秒停頓、短暫紅閃、左右擊退＋拋飛、落地小彈一次再滑停，牆壁仍實心。受擊期間暫停 AI 與出手，所有位移由敵人 CharacterController 處理，不拉動玩家。
VisualRoot 可換正式美術；EnemyHitResponse.onHit / onBounce / onRecovered 接受擊、彈地及起身動畫，死亡後不觸發起身事件。血量條與暫時閃色可日後替換。

EnemyDepthPresentation 預留深度特效介面：State = SameDepth / InFrontOfPlayer / BehindPlayer，預設同深度容許差 0.25。SignedDepthDifference 以當前視角深度軸計算，正值在玩家後方、負值在前方。
可拖入 sameDepthEffect / frontEffect / behindEffect 子物件，狀態切換自動顯示對應特效；亦可接 onStateChanged 與 onDepthDifferenceChanged 做材質、透明度或粒子參數。
目前不附正式特效，只提供狀態、引用與事件。此元件不改變碰撞、傷害或角色位置。

### 高速下落近戰處決

PlayerMeleeAttack.enableFallingExecution 預設啟用，fallingExecutionSpeed 預設 10 單位／秒（測試值）；可調門檻或關閉。
處決使用獨立腳下範圍：基礎左右各 0.6，額外納入玩家碰撞箱半寬後再左右擴大 5%；向上到玩家碰撞箱中心（包含下半身）、往下 1.2、視角深度差最多 3。敵人碰撞箱與這個區域接觸即可，不要求敵人中心低於玩家中心。此範圍不受一般橫向近戰的朝向、reach、verticalReach 限制，起跳即顯示橘色框，Scene 選中玩家可看立體範圍。
玩家在空中、敵人位於處決範圍時按過攻擊，這次滯空期間的最高下落速度達門檻，而且敵人直到玩家落地都沒有離開範圍，落地時便可處決。攻擊輸入會記錄當時範圍內的敵人；敵人離開範圍就失去資格。落地處決仍需通過鏡頭可見／遮擋判定，單純踩到敵人不觸發。
從起跳開始顯示處決範圍與目前範圍內可受擊敵人的提示，不等待速度達標才偵測。下落速度只在落地結算時檢查；提示代表玩家在此處按攻擊可登記目標，敵人若在落地前離開範圍就會取消。
處決輸入獨立於一般攻擊前搖／收招：空中重按攻擊仍會登記當時範圍內目標，不會額外連發一般攻擊；受擊、閃避、旋轉及死亡時不接收新處決輸入。落地以最後一個空中碰撞箱位置、視角軸及最高下落速度結算，避免接地後的平台深度對齊影響結果。空中顯示已登記目標數與最高速度；未登記、目標離開、速度不足、無敵及遮擋均有測試提示。
處決直接清空當前血量，屬普通 1 傷害規則的明確例外；仍尊重無敵狀態，保留受擊、死亡與重生事件。onExecution 可接正式處決特效／音效，成功時顯示「下落處決！」。

### 追擊範圍鎖定

近身攻擊例外：敵人與玩家的實體 CharacterController 膠囊表面最短 3D 距離在 0.5 單位內時，忽略視野、朝向與遮擋，可開始攻擊；仍保留前搖與攻擊間隔，出手時重新檢查。此距離不採中心點，避免玩家站在旁邊方塊上時因高度差而漏判。返回巡邏中的敵人仍不攻擊。
攻擊深度上限預設 3 格，以當前視角深度軸計算。超過時先追近，取消出手後的收招不阻擋追擊移動；追到 2.75 格內才退出深度優先，避免 3 格邊界抖動。頭頂狀態顯示目前深度差，Console 亦附此數值。

`pursuitLockRadius` 預設 2 單位，以敵人目前位置到玩家位置的 3D 距離判斷；設為 0 可關閉。敵人須先透過視野發現玩家，尚未被發現的背後玩家不會單憑靠近就觸發鎖定。
已發現／追擊的玩家進入範圍後，敵人持續知道玩家位置；繞背或被牆遮住不再解除追擊。仍經由實體 A* 找路，且攻擊必須通過原有距離、前搖、方向與牆壁遮擋檢查。
鎖定期間不因出生點追擊半徑、追擊時間或找路失敗而放棄；不可達時持續嘗試最近可達地板。此規則優先於舊的追擊限制。
玩家離開範圍或死亡才解除鎖定；未看見玩家時，使用鎖定期間最後確認的位置調查、觀察再返回。若仍看得到玩家，普通目視追擊仍可繼續。解鎖後恢復出生點半徑與追擊時間限制；已在返回流程中的敵人不重新鎖定。

## 玩家受擊

PlayerCombatStatus 在 Health 確認扣血後呼叫主玩家的 ApplyHitResponse，無敵期間不會重複擊退。
方向沿當前視角左右遠離傷害來源；來源剛好同水平位置時沿上次受擊方向（首次向左）。
PlayerController 可調 hitPause（0.045 秒）、knockbackSpeed（7）、knockbackDuration（最少鎖定 0.65 秒）、hitLaunchSpeed（5）、hitBounceSpeed（2.4）、hitGroundFriction（9）、hitAirDrag（1.5）、hitMaxLockDuration（最多鎖定 2 秒）。
停頓只影響受擊玩家。受擊後拋飛，第一次落地彈起一次並保留 70% 水平速度，再落地滑行；地面摩擦低於正常移動的減速。速度接近零且落地後恢復操作，超過最長時間亦解除鎖定，防止掉出地圖後無法操作。期間鎖住移動、跳躍／下落、技能與互動，保留 F8／F9 測試功能。
位移走現有繞牆、支撐與 CharacterController 判定；撞牆停止推力，轉視角取消推力，F8 返回平台清除受擊狀態。
主玩家無敵時間為 0.45 秒。PlayerCombatStatus.onHit 可接動畫、閃白、音效；目前以血量框變紅提示，未加入正式美術效果。
PlayerController.onHitBounce 與 onHitRecovered 可分別接彈地和恢復動畫；正式動畫不要直接移動根物件。
